## 第1章调整

主要修正：

- 把工具／Agent 的本体二分改为 Delegated Interpretation、Action Surface 与 Feedback Horizon；
- 删除“Agent 首次拥有路径选择”的历史断言；
- 不在第1章正式定义 AI-assisted、Agentic、AI-native；
- 将三者从层级阶梯改为第3章定义的执行委托与工程适配双轴；
- 将“Agent 拥有实现路径”改为“部分路径决策被委托”；
- 保留两个复杂性，并增加条件性的 Delegated Execution Complexity；
- 明确 Human Authority 不等于人工微操。

本稿约为原稿字符量的 54%。主要压缩对象是重复结论、原则与反模式，不表示所有历史叙事已经完成恢复。

## 第2章调整

主要修正：

- 把“七项历史隐含假设”改为七项操作条件和 Failure Signal；
- 保留传统软件工程已处理部分相同风险的反向事实；
- 将“隐性知识必须显式工程化”收窄到复杂度、并发、风险和恢复成本触发；
- 将未取证的 Behavior Distribution 改为 Allowed Behavior Set 与 Observed Variations；
- 删除 `Doc/Code/Runtime/Memory Truth Hierarchy`；
- 区分 Capability 与实际治理强度；
- 分开 Test、Acceptance、Adoption 与 Release；
- 保留 `CLM-C02-001` 的 `partial / unreviewed` 证据边界。

本稿约为原稿字符量的 60%。它是完整诊断逻辑首稿，但仍可从原稿恢复更多历史例子和工程叙事。

## 第3章调整

主要修正：

- 工作定义增加“真实执行路径委托”和“工程环境适配”两个同时条件；
- AI-assisted、Agentic、AI-native 不再构成单轴成熟度；
- 保留 Product System 与 Production Intelligence System 两个系统；
- Control and Evidence Plane 改为横切平面，不再作为第三个同级生产系统；
- Harness Engineering 与 AI-native 改为重叠范围，不声明行业公认集合从属；
- 六类 Boundary 改为工作检查表，不声称穷尽所有项目；
- `Contract over Reasoning Process` 收窄为管理可观察对象、不依赖隐藏推理；
- 删除统一 Evidence 强弱阶梯；
- 分开 Validation Coverage 与 Decision Disposition；
- 将第五／六章相关生命周期改为迭代循环；
- 将 Adaptive Governance 改为风险与成本适配，不建立成熟度等级。

本稿约为原稿字符量的 52%。它覆盖原稿的核心理论职责，但没有恢复所有展开、重复原则和 Harness 补充材料。

## 第4章调整

主要修正：

- 只有由 Intent 派生的 Task 才必须保存 Parent Intent；其他 Task 保存 Trigger Source；
- Prompt 统一为 Agent Input 的指令／消息表达层；
- Intent Schema 使用 State、Assumption、Decision 与 Evidence Requirement 引用，不吸收运行态对象；
- Execution 示例使用具名 `evidence_verified / implementation_scope_rejected / adoption_not_decided`；
- Acceptance Mapping 增加 `decision_target`、Scope 与 Non-goal；
- 风险未知进入已授权处置路径，不机械等同于询问 Human；
- 增加产品、技术、安全、体验、成本与合规之间的多方 Intent 冲突接口。

当前文件仍是对象边界稿，约为原稿字符量的 36%。它不应被误称为完整第4章成稿。

## 第5章调整

主要修正：

- 分开 Contract、Pack、Manifest、Access Log 与不可直接观察的 Interpretation；
- Manifest 记录装配、传输或开放访问，不证明模型注意或使用；
- `Context Quality 正交维度` 改为不可压缩成单分数的相互制约检查项；
- 拆开 Hot/Warm/Cold Storage Tier 与 expired/invalidated Validity；
- Role Projection 决定访问与获准依赖，不产生认识论真实性；
- State Snapshot、Context Manifest、Execution Snapshot 与 Handoff 重新分工；
- 增加 Project Memory 与 Skill 的内容、Procedure、Instruction 和 Tool Authority 边界；
- 将第五／六章改为 Progressive Retrieval 与 Typed Record Resolution 的反馈关系。

当前文件仍是对象边界稿，约为原稿字符量的 37%。它不应被误称为完整第5章成稿。

## 第6章调整

主要修正：

- 分开 Descriptive Support 与 Authorized Use；
- “五类记录必须分开”改为“五种语义角色必须可区分”；
- State Claim 拆分 Formation、Coverage、Evidence Relation、Conflict、Lifecycle 与 Disposition；
- 分开 Authority Grant 与 Authority Applicability；
- 修复 Decision `active/superseded` 与 `temporary` 轴混用；
- 按对象类型处理 Assumption 被反驳后的重新验证、审议和授权；
- `non-result` 只由目标未形成观察推出；目标在改变后输入上被观察时记录实际对象；
- Context Manifest 不声称模型认知状态；State Snapshot 明确有界；
- Execution Baseline Manifest 收窄为 typed-reference assembly；
- State Compression 示例改用 State Claim，不再把 Decision 塞进 State；
- `Decision Environment Reproducibility` 改为 Traceability 与有限 Reconstructability Goal；
- Freshness 区分 Historical Validity 与 Current Applicability；
- D-048 分开直接工程缺陷与本书结果语义推导；
- 风险档位改为说明性裁剪方式，不形成新治理等级。

当前稿约 28,178 字符，为原第6章约 91%。RR-017 恢复的 Decision/Assumption Lifecycle、Dirty Worktree、Drift、Readiness 与 State Index 内容均被保留。
